## Pendiente (causa raíz, aparte de este arreglo)

La edición profunda reescribía las líneas del despacho con identificadores nuevos y la
restricción `ON DELETE SET NULL` cortaba el enlace de `despacho_devoluciones.despacho_item_id`.
Al perderse ese enlace, la vista consolidada (pantalla y PDFs) dejaba de descontar lo devuelto y
mostraba los dos juegos de artículos. El arreglo de fondo está en
`src/services/despachoItemsService.js`: las devoluciones sin enlace se emparejan por producto.
